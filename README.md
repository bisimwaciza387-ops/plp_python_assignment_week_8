PLP Python Week 8 — My Python Toolkit
What This Toolkit Does

This project is a small Python toolkit containing three useful tools.

toolkit_plan.txt — Contains the plan and blueprint for the toolkit.

toolkit.py — Contains the main menu and all three working tools.

screenshots/ — Contains screenshots showing the menu and each tool running.

Tools

Number Checker — Checks whether a number is positive, negative, or zero.

Shopping List — Allows the user to add, remove, and view shopping list items.

Multiplication Table — Prints a multiplication table from 1 to 10.

How to Run

Make sure Python is installed on your computer.

Open a terminal in the project folder and run:

python toolkit.py

Follow the numbered menu to select a tool. Choose option 4 when you want to quit.

Reflection

The hardest part of this project was connecting all the different tools to one main menu. The shopping list took the longest to test because the list has to change while the program is running. One bug I had to pay attention to was making sure an item was in the list before trying to remove it. I also had to make sure an invalid menu choice did not crash the program. Testing each menu option helped me understand how loops and conditionals work together. I learned that using functions makes a larger program easier to organize and understand. With one more week, I would add a simple calculator and save the shopping list to a file so that it could be used again later.
